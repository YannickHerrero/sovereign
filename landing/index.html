The complete guide ↗
01

Prepare your machine

Install and authenticate a supported harness — pi or Claude Code today — plus Rust, Node.js, pnpm, and Tailscale. Start with your own environment.

02

Install Sovereign

Build the PWA, then the server. On first launch, an access token is created in your local configuration.

03

Connect your phone

Expose the server with Tailscale Serve. Open its HTTPS URL, add the PWA to your home screen, and configure your machine.

Terminal — installation 
# Get the project
git clone https://github.com/YannickHerrero/sovereign.git
cd sovereign

# Build the interface and install the server
cd pwa && pnpm install && pnpm build
cd ../server && cargo install --path .

# Start on this machine
sovereign-server
Then, in another terminal: tailscale serve --bg 7777

GOOD TO KNOW

A few
answers.

Which coding agents can I use?

Sovereign is independent of the harness, the tool that runs your agent. pi and Claude Code are supported today; you only need one of them. Codex and OpenCode are planned, but not yet available. Each integration requires an adapter. The server detects compatible tools at startup. Choose the harness through the model when creating a task; it stays associated with that task.

Is it just for phones?

No. The interface also works on desktop, with tasks grouped by date or project, a full-width mode, and a diff view for reviewing changes. On mobile, you can install it as a PWA.

Where do my agents run, and where does my code go?

Agents run on your machines. Sovereign does not provide a cloud relay. Your agents still send the context they need to their model providers, according to their configuration. Optional voice dictation uses OpenAI.

How do I secure remote access?

The server listens on localhost by default and requires an access token. Tailscale Serve provides HTTPS access within your Tailscale network. Keep your token secret and do not expose the server directly to the Internet.

Do agents ask for permission?

Claude Code runs in bypassPermissions mode: it does not ask for confirmation before taking action. Only use Sovereign with trusted repos and machines, and review the changes. pi’s behavior depends on your configuration.

Do I need another subscription?

You build and self-host Sovereign on your own infrastructure, without a Sovereign account. Any costs from your model providers and existing services still apply. See the repository for installation instructions.
