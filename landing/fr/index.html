Le guide complet ↗
01

Préparez votre machine

Un harness compatible installé et authentifié — pi ou Claude Code aujourd’hui —, Rust, Node.js, pnpm et Tailscale. Tout part de votre environnement.

02

Installez Sovereign

Compilez la PWA, puis le serveur. Au premier lancement, un token d’accès est créé dans votre configuration locale.

03

Connectez votre téléphone

Exposez le serveur avec Tailscale Serve. Ouvrez son URL HTTPS, ajoutez la PWA à l’écran d’accueil et configurez votre machine.

Terminal — installation 
# Récupérer le projet
git clone https://github.com/YannickHerrero/sovereign.git
cd sovereign

# Compiler l’interface et installer le serveur
cd pwa && pnpm install && pnpm build
cd ../server && cargo install --path .

# Démarrer sur cette machine
sovereign-server
Puis, dans un autre terminal : tailscale serve --bg 7777

BON À SAVOIR

Quelques
réponses.

Quels agents puis-je utiliser ?

Sovereign est indépendant du harness, l’outil qui exécute votre agent. Aujourd’hui, pi et Claude Code sont pris en charge ; un seul des deux suffit. Codex et OpenCode sont prévus, mais pas encore disponibles. Chaque intégration nécessite un adaptateur. Le serveur détecte les outils compatibles installés au démarrage. Choisissez le harness via le modèle lors de la création d’une tâche ; il reste ensuite associé à cette tâche.

Est-ce uniquement pour le téléphone ?

Non. L’interface s’adapte aussi au desktop, avec une liste de tâches par date ou projet, un mode pleine largeur et une vue diff pour relire les changements. Sur mobile, elle s’installe comme une PWA.

Où s’exécutent mes agents et où va mon code ?

Les agents s’exécutent sur vos machines. Sovereign ne fournit pas de relais cloud. Vos agents continuent toutefois à transmettre le contexte nécessaire à leurs fournisseurs de modèles, selon leur configuration. La dictée optionnelle utilise OpenAI.

Comment sécuriser l’accès à distance ?

Le serveur écoute sur localhost par défaut et exige un token d’accès. Tailscale Serve fournit l’accès HTTPS au sein de votre réseau Tailscale. Gardez votre token secret et n’exposez pas directement le serveur sur Internet.

Les agents demandent-ils des permissions ?

Claude Code est lancé en mode bypassPermissions : il ne demande pas de confirmation avant ses actions. Utilisez Sovereign uniquement sur des repos et des machines de confiance, et relisez les modifications. Le comportement de pi dépend de votre configuration.

Faut-il un abonnement supplémentaire ?

Sovereign se compile et s’héberge sur votre infrastructure, sans compte Sovereign. Vous conservez les coûts éventuels de vos fournisseurs de modèles et de vos services existants. Consultez le dépôt pour les instructions d’installation.
